# 📱 SMS Sender

> Отправка SMS через ADB с графическим интерфейсом.
> Не требует root и использует эмуляцию действий на Android-устройстве.

---

## ⚙️ Возможности

* 📱 Отправка SMS на указанный номер через ADB
* 🇷🇺 Поддержка русского текста
* 🌑 Тёмный графический интерфейс на `tkinter`
* 🔓 Не требует root-доступа
* ⚡ Асинхронная отправка — интерфейс не блокируется во время выполнения
* 👆 Автоматическая эмуляция нажатия кнопки «Отправить»
* 🔌 Поддержка подключения устройства по USB или Wi-Fi

---

## 🛠 Требования

* **Python 3.10+**
* **Android Debug Bridge (ADB)**
* Android-устройство с включённой отладкой
* Подключение устройства по USB или Wi-Fi
* `tkinter`

### Установка ADB

Скачай Android SDK Platform Tools с официального сайта Android:

https://developer.android.com/studio/command-line/adb

После установки убедись, что команда `adb` доступна из терминала:

```bash
adb version
```

Проверь подключённые устройства:

```bash
adb devices
```

Устройство должно появиться в списке.

## 📱 Настройка координат кнопки «Отправить»

Приложение автоматически эмулирует нажатие кнопки отправки SMS.

По умолчанию используются координаты:

```python
SEND_X = 1121
SEND_Y = 2437
```

Если разрешение экрана или интерфейс приложения сообщений отличаются, координаты необходимо изменить.

Например:

```python
SEND_X = 1000
SEND_Y = 2200
```

Для проверки координат можно использовать:

```bash
adb shell input tap <x> <y>
```

> **Примечание:** `adb shell getevent -l` показывает низкоуровневые события ввода и не всегда является удобным способом определения координат. Для точного позиционирования также можно использовать инструменты разработчика или отображение координат касаний на самом Android-устройстве.

## 🧠 Принцип работы

SMS Sender работает следующим образом:

1. Программа подключается к Android-устройству через ADB.
2. Открывается приложение сообщений с помощью `Intent SENDTO`.
3. В Intent передаётся номер телефона.
4. В поле сообщения передаётся текст.
5. После небольшой задержки программа эмулирует нажатие кнопки «Отправить».
6. Результат операции отображается в графическом интерфейсе.

Упрощённая схема:

```text
Python GUI
    │
    ▼
   ADB
    │
    ▼
Android Intent
    │
    ▼
Приложение SMS
    │
    ▼
Заполнение номера и сообщения
    │
    ▼
ADB input tap
    │
    ▼
Отправка SMS
```
